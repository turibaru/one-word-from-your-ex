Entry for the make.fun bounty [One Word From Your Ex](https://make.fun/bounty/u-brave-eagle-12-one-word-from-your-ex-cfd97ba2): exactly one word your ex would use to describe you — the funniest, most painfully honest word takes the whole reward.

## Run

```sh
MAKEFUN_OUTPUT_DIR=/path/to/out node main.ts
```

`main.ts` reads `entry.txt` from this repository and writes its single word to `$MAKEFUN_OUTPUT_DIR/entry.txt`. No network, no dependencies.
